Приоритетные правки

  1. [high/S] Meta description 70–160 символов — 0 симв
    Написать description 70–160 символов с ключом и CTA (поднимает CTR в выдаче).
  2. [high/S] Viewport (мобильная адаптация)
    Добавить <meta name="viewport" content="width=device-width, initial-scale=1">.
  3. [high/S] Ровно один H1 — h1=0
    Оставить один H1 с главным ключом; остальные заголовки понизить до H2/H3.
  4. [medium/M] TTFB < 800 мс (скорость ответа) — 2097ms
    Ускорить сервер: кэш, CDN, PHP/БД-оптимизация; цель TTFB < 800 мс, LCP < 2.5 c.
  5. [medium/S] Атрибут lang у <html> — нет
    Добавить lang (напр. <html lang="ru">) — помогает поиску и скринридерам.
  6. [medium/S] Open Graph (og:title/description/image ≥2) — 0/3
    Добавить og:title/og:description/og:image — красивые превью в соцсетях и мессенджерах.
  7. [low/M] Умеренное число внешних ресурсов (≤25 скриптов+стилей) — js=24 css=2
    Сократить/объединить внешние CSS/JS, отложить неважное (defer/async), убрать дубли.
  8. [low/S] Twitter Card размечена — нет
    Добавить <meta name="twitter:card" content="summary_large_image"> (+title/description).
  9. [low/M] Структурные данные (JSON-LD) — нет
    Добавить schema.org JSON-LD (Organization/Article/Product/FAQ) — расширенные сниппеты.
