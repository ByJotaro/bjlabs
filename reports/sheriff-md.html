Приоритетные правки

  1. [high/S] Meta description 70–160 символов — 0 симв
    Написать description 70–160 символов с ключом и CTA (поднимает CTR в выдаче).
  2. [high/S] Viewport (мобильная адаптация)
    Добавить <meta name="viewport" content="width=device-width, initial-scale=1">.
  3. [high/S] Ровно один H1 — h1=0
    Оставить один H1 с главным ключом; остальные заголовки понизить до H2/H3.
  4. [high/S] Canonical указан — нет
    Добавить <link rel="canonical" href="..."> с каноническим URL страницы.
  5. [high/M] Нет mixed-content (http-ресурсы на https) — http-ресурсов=11
    Перевести все src/href на https или относительные URL; браузеры блочат http-ресурсы.
  6. [medium/S] IMG alt у всех картинок — img=28 без alt=9
    Дописать осмысленные alt (ключ где уместно) всем <img>; декоративным — пустой alt="".
  7. [medium/S] Open Graph (og:title/description/image ≥2) — 0/3
    Добавить og:title/og:description/og:image — красивые превью в соцсетях и мессенджерах.
  8. [medium/M] Security-заголовки (≥2 из 5) — 0/5: нет
    Включить HSTS, CSP, X-Content-Type-Options, X-Frame-Options/frame-ancestors, Referrer-Policy.
  9. [medium/S] H2-подзаголовки есть — h2=0
    Разбить текст H2-подзаголовками с второстепенными ключами (структура + удержание).
  10. [low/S] Ссылки с непустым анкором — ссылок=100 пустых=3
    Дать всем <a> осмысленный текст/aria-label; пустые ссылки и «click here» переписать.
  11. [low/S] Порядок заголовков без пропусков (H1→H2→H3) — заголовков нет
    Не прыгать через уровень (после H1 — H2, не H3); починить иерархию заголовков.
  12. [low/S] Twitter Card размечена — нет
    Добавить <meta name="twitter:card" content="summary_large_image"> (+title/description).
  13. [low/M] Структурные данные (JSON-LD) — нет
    Добавить schema.org JSON-LD (Organization/Article/Product/FAQ) — расширенные сниппеты.
