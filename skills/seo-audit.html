Технический SEO-аудит как skill для AI-агента

Тот же аудит из 25 проверок, который я делаю для клиентов, упакован в SKILL.md. Агент запускает Python-скрипт по одной ссылке и получает скор 0–100, наблюдённые значения и приоритетные правки.

Открыть бесплатный skill на Agensi Посмотреть пример отчёта

Что проверяет

  • HTTP 200, HTTPS, случайный noindex
  • title, meta description, H1/H2, canonical
  • robots.txt, sitemap.xml, Open Graph, JSON-LD
  • alt, вес HTML, TTFB, security-заголовки
  • mixed content, ссылки, charset, favicon

Что получает агент

  • JSON: score, grade, 25 проверок, fixes
  • Markdown-отчёт для клиента
  • HTML-отчёт для браузера
  • severity и effort для каждой правки
Как это работает. Агент подключается к Agensi MCP, вы просите проверить одну публичную страницу, он загружает skill и запускает scripts/audit_url.py. Никаких API-ключей и браузера: только Python 3.9+ и сеть. Это диагностика, не гарантия позиций.

Кому подходит

Фрилансерам и агентствам для быстрого пре-флайта, владельцам сайтов для проверки после правок, разработчикам для регрессии метаданных. Одна страница за запуск; для сайта запускайте по ключевым URL.
